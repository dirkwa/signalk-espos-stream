# Contributing

This is a personal project, so contributions are unlikely — but the terms are
stated here so they are settled if that changes.

Before opening a PR:

```bash
npm run format   # prettier + eslint --fix
npm run build    # tsc + webpack (config panel)
npm test         # typechecks + vitest
```

Commits follow
[Angular conventional commit](https://www.conventionalcommits.org/) format, and
branch names use hyphens rather than slashes.
